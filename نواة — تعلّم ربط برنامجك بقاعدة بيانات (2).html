منهج الكورس

ست عشرة محاضرة قصيرة: أساسيات، ثم مواضيع متقدمة مثل النسخ الاحتياطي وتعدد المستخدمين والأداء.

مختبر SQL

جرّب أوامر SQL بنفسك بأمان: كل شي يصير داخل المتصفح ولا يمس أي بيانات حقيقية. اتبع التمارين بالترتيب.

التمارين

ما المدعوم في المختبر؟

create table · insert · select (مع where وand/or وlike، وjoin وleft join، وgroup by، وorder by، وlimit، ودوال count/sum/avg/min/max) · update · delete · drop table. أسماء الجداول والأعمدة بالإنجليزية، وشرط الربط بعمودين فقط.

تحدٍّ

اكتب أمرك في المحرر ثم اضغط «تحقق». يُختبر على جداول تجريبية جاهزة (expenses وcustomers وorders) ولا يمس جداولك.

نسخة احتياطية كنص

صدّر جداولك كنص JSON وانسخه، ثم امسح الجداول وجرّب الاستعادة منه.

برنامج التجربة: أول ربط حقيقي

برنامج مصاريف صغير جاهز، تشغّله على حاسوبك وتربطه بقاعدة بياناتك بنفسك. فيه «فاحص اتصال» يقول لك شنو المشكلة إذا ما اشتغل.

الخطوة 1

جهّز الجدول

في Supabase افتح SQL Editor ← New query، والصق هذا الكود واضغط Run.

هذي السياسات للتجربة فقط: تسمح لأي شخص يملك المفتاح العام بالقراءة والإضافة والحذف. استخدم بيانات وهمية، وبعدها نشدّدها بسياسات المستخدمين (المحاضرتان 6 و11).

الخطوة 2

افحص مفاتيحك قبل الاستخدام

من Project Settings ← API انسخ Project URL والمفتاح العام (anon أو publishable). الفحص يتم داخل هذه الصفحة فقط ولا يرسل شيئاً لأي مكان.

الخطوة 3

احفظ برنامج التجربة وشغّله

انسخ الكود، والصقه في Notepad، واحفظه باسم expenses-test.html (اختر «All files»)، ثم افتحه بالمتصفح، والصق الرابط والمفتاح، واضغط «حفظ وفحص الاتصال».

ليش الفاحص داخل الملف وليس هنا؟ لأن هذي الصفحة تمنع الاتصال بمواقع خارجية، أما ملف على جهازك فما عنده هالقيد.
